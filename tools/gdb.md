# commands

```shell
help  #看指令帮助
run   #运行
start #在一开始下断点
kill  #杀死当前程序
step  #s单步但进入函数
next  #n单步但不进入函数
finish #完成当前函数
until #u执行到特定行或循环结束
stepi/nexti #汇编单步

break/continue #b/c断点

frame     #f选择和打印栈帧
backtrace #bt回溯调用栈,-full完整的回溯

print #p打印
list  #l列出当前代码
layout #代码布局
tui disable/enable #终端的ui
```
